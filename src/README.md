# src

Open3D / segmentation / angle-paint code goes here.

`open3d_smoke.py` imports Open3D and prints `open3d.__version__`. It does not open a cloud. Install with `pip install -r requirements.txt` from the repo root (see the root README for the Windows venv steps).

The classical segment-and-box script lives in [`scripts/classical_segment_obb.py`](../scripts/classical_segment_obb.py).
